# Sri Mens Street Wear — Client Frontend

React + Vite frontend for **Sri Mens Street Wear** Billing & Retail Management System.

## Features
- **Manual Item-Entry Billing Table**: Columns: `Sno | Cloth | Price | Discount | Total`
- **Instant Calculations**: Row Total = Price - Discount, Grand Total = Sum of Item Totals
- **Fast Checkout & Printing**: One-click printable invoices with custom store styling
- **Mobile Responsive**: Tested across 320px, 360px, 375px, 390px, 430px, tablet, and desktop viewports
- **Mobile Drawer Navigation**: Hamburger menu with Escape-key dismiss and touch accessibility
- **Analytics Dashboard**: 7-day sales trend charts and payment breakdown
- **Reports & PDF Export**: Range filters and auto-formatted PDF downloads
- **Clothing Catalog**: Reference standard garments, sizes, and colors
- **Expense Tracking**: Retail overhead management (stock purchases, rent, utilities, wages)

## Scripts
```bash
# Start Vite development server (port 5173)
npm run dev

# Build production bundle (client/dist)
npm run build

# Preview production build
npm run preview
```
